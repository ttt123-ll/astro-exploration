# 启动公网演示隧道（Cloudflare Quick Tunnel）

本项目使用 **Cloudflare Quick Tunnel** 提供临时公网访问地址（无需账号、免费、HTTPS）。
地址形如 `https://xxxx-xxxx.trycloudflare.com`，**每次重启隧道都会变化**。

## 一键启动（Windows）

```powershell
powershell -ExecutionPolicy Bypass -File tools\start-tunnel.ps1
```

脚本会：

1. 检查本机站点是否运行（`http://127.0.0.1:3001/api/health`）
2. 启动 `cloudflared` 隧道（默认映射 3001 端口）
3. 等待并打印公网地址，同时写入 `F:\离线分发包\在线演示地址.txt`

## 手动启动

```powershell
# 1. 确认站点在跑
curl http://127.0.0.1:3001/api/health

# 2. 启动隧道（cloudflared 在 F:\离线分发包\cloudflared\）
F:\离线分发包\cloudflared\cloudflared.exe tunnel --url http://127.0.0.1:3001 --no-autoupdate
```

终端输出中的 `https://xxx.trycloudflare.com` 即为公网地址。

## 停止隧道

```powershell
Get-Process cloudflared | Stop-Process -Force
```

## 当前地址

运行 `powershell -ExecutionPolicy Bypass -File tools\start-tunnel.ps1` 后，地址会打印在终端并写入
`F:\离线分发包\在线演示地址.txt`（每次重启隧道地址会变化）。

## 注意事项

| 项目 | 说明 |
|---|---|
| 保持在线 | 电脑需开机、不休眠；隧道进程关闭后地址立即失效 |
| 地址变化 | 重启隧道会获得新地址，请重新复制到提交材料 / 发给评审 |
| 性能 | 经 Cloudflare 中转，首次加载比本地慢 1-2 秒，属正常现象 |
| 安全 | 公网期间站点使用内置 AI Key，请勿长期公开；评审结束可立即停止隧道 |
| 评审账号 | `admin / admin123`（管理员）；普通用户可在注册页注册（需绑定邮箱） |
| 演示模式 | 未配置 SMTP 时找回密码验证码直接显示在页面弹窗中 |

## 备用方案

如 Cloudflare 不可用，可换用任意内网穿透工具（如 frp / ngrok / 花生壳），
把本地 `3001` 端口映射到公网 HTTPS 即可，站点本身无需改动。
