## 第 3 页 · 作品总览

- 视觉：四宫格截图（首页/百科/3D/社区）

## 第 4 页 · 系统架构

- 前端：Vue 3 + Vite + Router + Pinia + Three.js
- 后端：Express + MySQL + JWT；安全中间件（CSP/限流/参数化）
- AI 层：意图 → RAG 检索 → Prompt → LLM/本地知识库 → SSE 流式
- 部署：Docker Compose（App + MySQL）离线可跑
- 视觉：架构图（前端 / Express / AI / 数据四层）

## 第 5 页 · RAG 技术方案

- 知识库：52 篇文档 → 149 知识块，来源可回溯页面
- 检索：1024 维哈希向量 + 词法 TF-IDF，混合权重 0.62 / 0.38
- 过滤：相关度阈值 0.26；Top-K 4-6
- 评测：Hit@1 90%、Hit@3 100%、MRR 0.950（30 条标注查询）
- 视觉：检索流程图 + 指标卡片

## 第 6 页 · Function Calling 与 Agent 工作流

- 5 个工具：月相计算、今夜观星、装备导购、知识检索、页面导航
- 流程：模型规划 tool_calls → 服务端执行 → 结果注入 → 流式生成
- 可视化：SSE `toolsUsed` + 前端工具徽标
- 兜底：推理模型跳过规划；无 Key/断网走规则工具
- 视觉：截图（月相问题 + 「月相计算」徽标）

## 第 7 页 · AI 安全与可控性

- 三级降级：大模型 → 本地检索 → 兜底引导
- 溯源：角标 + 来源卡片 + 原文跳转
- BYOK：用户 Key 只存浏览器、请求期使用；站点 Key 不下发
- 内容安全：超范围引导、科学争议声明、事实校订回归测试
- 视觉：降级链路图
