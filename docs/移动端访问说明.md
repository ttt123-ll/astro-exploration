# 移动端访问说明（H5 / PWA）

网站提供**桌面版与移动端两个入口**，手机上打开会自动进入响应式移动版；在电脑上打开 `/m` 可直接查看手机效果。

## 一、两个入口

| 入口 | 地址 | 说明 |
|---|---|---|
| 桌面版 | `https://你的域名/` | PC 布局 |
| 移动端入口 | `https://你的域名/m` | 电脑打开：显示 390×844 手机预览（手机外框 + 移动端页面）<br>手机打开：自动跳转到响应式移动版 |
| 手机直达 | `https://你的域名/` | 手机浏览器直接打开也是移动端布局（无需 /m） |

> 域名以 `F:\离线分发包\在线演示地址.txt` 中的公网地址为准（临时隧道地址每次重启会变）。
> 二维码已指向 `/m`：扫码后手机直接进入移动版；把同一个二维码给电脑扫不会显示手机页，电脑请直接访问 `/m`。

## 二、在电脑上查看移动端效果

1. 浏览器打开 `http://127.0.0.1:3000/m`（或公网 `.../m`）；
2. 页面会用 **390×844** 的手机尺寸加载网站，显示手机外框；
3. 框内即为移动端布局：底部 Tab（首页/星座/图集/AI/社区）、汉堡菜单；
4. 顶部按钮可切换「桌面版」，或「复制本页地址」发给别人。

> 也可以用开发者工具模拟：F12 → Ctrl+Shift+M → 选 iPhone 14 Pro（390×844）→ 刷新。

## 三、扫码 / 手机访问

- 扫码图：`F:\离线分发包\移动端-扫码访问卡.png`（二维码指向 `/m`）
- 手机浏览器建议：Chrome / Edge / Safari / 微信内置浏览器（微信内受限时点右上角「···」→「在浏览器打开」）

## 四、手机端已适配的能力

| 能力 | 说明 |
|---|---|
| 响应式布局 | 390px / 768px / 1024px 断点，导航收进汉堡菜单，无横向溢出 |
| 底部 Tab 栏 | 首页 / 星座 / 图集 / AI / 社区 一键切换 |
| AI 助手 | 移动端独立布局，流式输出、工具徽标、来源卡片正常 |
| 3D 星球投影 | 移动端降级交互，支持缩放与旋转 |
| PWA | HTTPS 下注册 Service Worker，可「添加到主屏幕」离线缓存 |

## 五、添加到手机桌面（PWA）

1. 用手机浏览器打开公网地址
2. **Android Chrome**：右上角菜单 →「添加到主屏幕」/「安装应用」
3. **iPhone Safari**：底部分享按钮 →「添加到主屏幕」
4. 之后从桌面图标打开，体验接近原生 App（仍依赖网络加载最新内容）

## 六、常见问题

| 问题 | 解决 |
|---|---|
| 手机打不开 | 确认电脑开机、`cloudflared` 进程在运行；地址是否已过期（重启隧道会变） |
| 电脑打开 `/m` 还是桌面版 | 确认访问的是 `/m` 或 `/m.html`；地址末尾不要漏掉 |
| 微信里打不开 / 提示风险 | 点右上角「···」→「在浏览器打开」 |
| 页面加载慢 | 经 Cloudflare 中转且依赖本机上行带宽，首次加载会比局域网慢，属正常 |
| 想局域网访问（不依赖隧道） | 手机与电脑同一 WiFi，访问 `http://电脑局域网IP:3000/m`（HTTP 下 PWA 不可用） |

> 安全提醒：公网地址可被任何拿到链接的人访问，且会消耗站点 AI Key 额度；演示结束请关闭隧道：
> `Get-Process cloudflared | Stop-Process -Force`
