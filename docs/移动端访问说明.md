# 移动端访问说明（H5 / PWA）

网站已内置移动端适配，**手机浏览器直接打开公网地址即可使用**，无需安装 App。

## 一、扫码 / 输入地址访问

- 公网地址见 `F:\离线分发包\在线演示地址.txt`（或 `提交材料\在线演示地址.txt`）
- 扫码访问图：`F:\离线分发包\移动端-扫码访问卡.png`（可直接发给评审 / 贴进 PPT）
- 手机浏览器建议：Chrome / Edge / Safari / 微信内置浏览器（若微信内受限，右上角「在浏览器打开」）

## 二、手机端已适配的能力

| 能力 | 说明 |
|---|---|
| 响应式布局 | 390px / 768px / 1024px 断点，导航收进汉堡菜单，无横向溢出 |
| 底部 Tab 栏 | 首页 / 星座 / 图集 / AI / 社区 一键切换 |
| AI 助手 | 移动端独立布局，流式输出、工具徽标、来源卡片正常 |
| 3D 星球投影 | 移动端降级交互，支持缩放与旋转 |
| PWA | HTTPS 下注册 Service Worker，可「添加到主屏幕」离线缓存 |

## 三、添加到手机桌面（PWA）

1. 用手机浏览器打开公网地址
2. **Android Chrome**：右上角菜单 →「添加到主屏幕」/「安装应用」
3. **iPhone Safari**：底部分享按钮 →「添加到主屏幕」
4. 之后从桌面图标打开，体验接近原生 App（仍依赖网络加载最新内容）

## 四、常见问题

| 问题 | 解决 |
|---|---|
| 手机打不开 | 确认电脑开机、`cloudflared` 进程在运行；地址是否已过期（重启隧道会变） |
| 微信里打不开 / 提示风险 | 点右上角「···」→「在浏览器打开」 |
| 页面加载慢 | 经 Cloudflare 中转，首次加载比局域网慢 1-2 秒，属正常 |
| 想局域网访问（不依赖隧道） | 手机与电脑同一 WiFi，访问 `http://电脑局域网IP:3001`（HTTP 下 PWA 不可用） |

> 安全提醒：公网地址可被任何拿到链接的人访问，且会消耗站点 AI Key 额度；演示结束请关闭隧道：
> `Get-Process cloudflared | Stop-Process -Force`
