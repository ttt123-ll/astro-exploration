# 演示视频脚本（5-8 分钟，MP4 / 1080p / 普通话）

> 用途：传智杯省赛作品提交（要求 5-8 分钟，含项目介绍、核心功能演示、AI 技术亮点）
> 录制建议：1920×1080，浏览器全屏（F11），系统缩放 100%，Chrome/Edge；先关闭无关标签页与通知；旁白后期配音或用手机提词器。

## 0. 录制前准备（约 5 分钟）

1. 启动站点：`http://127.0.0.1:3001`（Docker 版），确认 AI 页显示「AI 大模型 · 在线」。
2. 准备两个窗口：网站 + 演示 PPT（可选，用于片头片尾）。
3. 准备演示账号：`admin / admin123`；另备一个新注册的普通账号（提前注册好，绑定邮箱）。
4. 准备 3 个 AI 提问：
   - 「今晚适合看什么？我在北京」（观星推荐）
   - 「预算 500 元，新手想拍月亮，买什么望远镜？」（装备导购）
   - 「创生之柱真的被摧毁了吗？」（事实边界 + 溯源）
5. 准备 1 个演示「深度推理」的复杂问题：「为什么木星有这么大的磁场？」
